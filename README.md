# CIVORA — Build. Manage. Evolve.

3D shahar qurish o'yini (Three.js). Telefon va brauzer uchun.

## GitHub Pages'ga joylash
1. github.com'da yangi repozitoriya yarating (nomi: `civora`, Public).
2. "Add file → Upload files" orqali shu papkadagi hamma fayllarni yuklang (index.html, .nojekyll, assets/, README.md).
3. Settings → Pages → Source: "Deploy from a branch", Branch: `main`, papka: `/ (root)` → Save.
4. 1–2 daqiqadan keyin o'yin `https://<foydalanuvchi>.github.io/civora/` manzilida ochiladi.

## Papkalar
- `index.html` — o'yin (hozircha bitta fayl)
- `assets/models/` — tayyor 3D modellar (.glb): daraxt, buta, tosh, uy va boshqalar
- `assets/textures/` — teksturalar (keyingi bosqich)

## Modellar (keyingi bosqich)
`assets/models/README.md` faylida qaysi modellar kerakligi yozilgan.
